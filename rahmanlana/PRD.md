## 17. Deployment

Website harus siap deploy ke GitHub Pages.

Ketentuan:

- Project dapat dijalankan dengan `npm run dev`
- Project dapat di-build dengan `npm run build`
- Tidak ada error console utama
- File `vite.config.js` memiliki base sesuai nama repository GitHub
- Jika repository bernama `portfolio-react`, maka base adalah `/portfolio-react/`

Contoh konfigurasi `vite.config.js`:

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  base: '/portfolio-react/',
  plugins: [react(), tailwindcss()],
})
```

Jika repository menggunakan nama lain, sesuaikan bagian `base`.

Contoh:

```text
Nama repo: nor_rahman
Base: /nor_rahman/
```

## 18. GitHub Pages Workflow

Jika menggunakan GitHub Actions, buat file:

```text
.github/workflows/deploy.yml
```

Isi workflow:

```yml
name: Deploy React Portfolio to GitHub Pages

on:
  push:
    branches:
      - main

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Build project
        run: npm run build

      - name: Upload production build
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}

    runs-on: ubuntu-latest
    needs: build

    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

Catatan:

Jika Codex menambahkan workflow, pastikan tidak ada workflow deploy ganda yang membingungkan.
