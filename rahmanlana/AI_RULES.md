# AI Rules

1. Selalu baca PRD.md sebelum mengubah kode.
2. Jangan membuat fitur di luar PRD.md.
3. Jangan menyalin kode dari website referensi.
4. Referensi desain hanya digunakan sebagai inspirasi.
5. Jangan membuat backend, database, login, admin panel, CMS, atau API.
6. Jangan membuat routing kompleks.
7. Jangan membuat link palsu.
8. Jangan menambahkan dependency baru tanpa alasan kuat.
9. Jangan menghapus struktur folder utama.
10. Jangan membuat konten pribadi yang tidak ada di PRD.
11. Gunakan React JS, Vite, JavaScript, dan Tailwind CSS.
12. Pisahkan data ke folder src/data.
13. Pastikan npm run dev dan npm run build berhasil.
14. Jika ada hal yang tidak jelas, pilih solusi paling sederhana sesuai PRD.
